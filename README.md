# Ohm's Law Calculator App

## Overview

The Ohm's Law Calculator is a simple Android application developed using MIT App Inventor. The application helps users calculate Voltage (V), Current (I), or Resistance (R) using Ohm's Law.

The app provides a user-friendly interface where users can select the parameter to calculate, enter the required values, and instantly obtain the result. This project demonstrates basic mobile application development, mathematical calculations, and event-driven programming using MIT App Inventor.

---

## Ohm's Law

The application is based on the fundamental electrical engineering equation:

V = I × R

Where:

- V = Voltage (Volts)
- I = Current (Amperes)
- R = Resistance (Ohms)

The application can calculate any one parameter when the other two values are provided.

### Voltage Calculation

V = I × R

### Current Calculation

I = V / R

### Resistance Calculation

R = V / I

## Working Principle

The application allows users to select the parameter they wish to calculate using a dropdown menu. Based on the selected option, the app dynamically changes the input labels and accepts the required values.

When the Calculate button is pressed, the application performs the corresponding Ohm's Law calculation and displays the result instantly on the screen.

The logic is implemented using MIT App Inventor blocks, making the application lightweight and easy to understand.
